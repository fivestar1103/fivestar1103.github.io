macOS와 Safari 버전, 앱 버전, 기대한 동작, 실제로 일어난 일을 적어 주세요. 호환성 문제라면 웹사이트나 플레이어 이름도 도움이 됩니다.

비밀번호, 비공개 영상 링크, 녹화·녹음 파일은 보내지 마세요. 스크린샷은 선택 사항입니다. 보내기 전에 개인정보를 지우세요.

처음 사용하기

  1. Safari 설정의 확장 프로그램에서 Subtitle Overlay를 켜세요. 응용 프로그램 폴더에서 앱을 열면 이 설정으로 바로 이동합니다.
  2. 영상이 있는 페이지를 여세요. Safari 도구 막대에서 Subtitle Overlay를 누르세요. Always Allow on This Website를 선택하세요. Safari 확장 프로그램은 처음에는 어떤 페이지에도 접근할 수 없습니다. 이 단계를 거치지 않으면 영상 위에 자막이 나타나지 않습니다.
  3. 영상을 재생하세요. 자막을 검색하거나 가지고 있는 자막 파일을 영상에 끌어 놓으세요.

테스트할 파일이 필요하면 샘플 영상과 자막 파일을 사용하세요. 자막 시간은 영상에 맞춰 두었습니다.

일부 브라우저 페이지와 영상 플레이어는 확장 프로그램을 제한하므로 호환성은 웹사이트에 따라 달라질 수 있습니다.

문제 해결

자막이 나타나지 않아요.

대부분 웹사이트 접근 권한이 원인입니다. 도구 막대에서 Subtitle Overlay를 누르세요. Always Allow on This Website를 선택하세요. 페이지를 새로고침하세요. 계속 나타나지 않으면 Safari 버전과 웹사이트 또는 플레이어 이름을 보내 주세요.

자막이 너무 빠르거나 늦어요.

,와 .를 누르면 0.5초씩 조절합니다. [와 ]를 누르면 0.1초씩 조절합니다. 페이지 오른쪽 가장자리에서 Sync Timeline을 여세요. 원하는 자막 줄을 현재 재생 시점에 맞출 수 있습니다. 내 영상과 같은 버전의 자막을 쓰면 보통 조절할 일이 줄어듭니다.

자막 검색 결과가 없어요.

더 짧은 제목으로 검색해 보세요. 언어 필터를 확인하세요. 검색은 OpenSubtitles를 사용하므로 서비스 상태와 일일 한도에 영향을 받습니다. 대신 Mac에 있는 자막 파일을 언제든 불러올 수 있습니다.

페이지 안에 삽입된 플레이어에서 작동하지 않아요.

일부 플레이어는 별도 프레임에서 실행됩니다. 해당 페이지를 연 상태에서 도구 막대 버튼을 누르세요. 접근 권한을 허용하세요. 페이지를 새로고침하세요. 계속 작동하지 않으면 사이트 이름을 알려 주세요. 확인하겠습니다.

어떤 자막 형식을 지원하나요?

SRT, SMI, VTT, ASS를 지원합니다. 한국어·일본어·중국어 문자 인코딩을 자동으로 감지해 오래된 파일도 첫 줄이 깨지지 않도록 엽니다.

사용 통계 공유를 끄려면 어떻게 하나요?

확장 프로그램을 여세요. Settings → General에서 사용 데이터 공유를 끄세요. 사용자가 직접 켜기 전에는 공유하지 않습니다. 공유 여부에 따라 앱 기능이 달라지지 않습니다. 수집하는 정보와 삭제 요청 방법은 개인정보 처리방침에서 확인하세요.
