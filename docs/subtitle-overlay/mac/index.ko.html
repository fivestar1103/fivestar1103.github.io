Subtitle Overlay for Mac

macOS용 Safari 확장 프로그램

어떤 영상에도
내 자막을 띄우세요.

SRT 파일을 영상에 끌어 놓으면 자막이 나타납니다.영상을 보면서 자막 모양과 시간을 조절하세요.

주요 기능

  • SRT, SMI, VTT, ASS 파일을 끌어 놓거나 확장 프로그램에서 불러올 수 있습니다.
  • 한국어·일본어·중국어 문자 인코딩을 자동으로 감지해 오래된 파일도 첫 줄이 깨지지 않도록 엽니다.
  • 페이지를 벗어나지 않고 OpenSubtitles에서 자막을 검색하고 불러올 수 있습니다.
  • 크기, 글꼴, 색상, 배경, 외곽선, 위치를 조절할 수 있습니다. 자막 크기는 화면에 맞춰 바뀝니다.
  • 영상을 재생하면서 단축키로 자막 시간을 0.5초 또는 0.1초씩 조절할 수 있습니다.
  • Sync Timeline에서 모든 자막 줄을 볼 수 있습니다. 원하는 시점으로 이동하거나, 자막 한 줄을 현재 재생 시점에 맞출 수 있습니다.
  • 같은 영상을 다시 열면 클릭 한 번으로 마지막 자막과 시간 설정을 복원할 수 있습니다. 복원 정보는 Mac에 보관합니다.
  • 앱 인터페이스는 9개 언어를 지원합니다.

구매를 결정하기 전에 사용해 보고 싶다면 샘플 영상과 자막 파일을 확인하세요. 자막 시간은 영상에 맞춰 두었습니다.

구매 방식

Mac App Store에서 한 번 구매하면 이 페이지에 설명한 모든 기능을 사용할 수 있습니다.

구독, 라이선스 키, 계정, 인앱 구매는 없습니다. 앱 자체에는 결제 기능이 없습니다.

설치 후 필요한 두 단계

  1. Safari 설정의 확장 프로그램에서 Subtitle Overlay를 켜세요.
  2. 영상이 있는 페이지를 여세요. Safari 도구 막대에서 Subtitle Overlay를 누르세요. Always Allow on This Website를 선택하세요.

Safari 확장 프로그램은 처음에는 어떤 페이지에도 접근할 수 없습니다. 그래서 두 번째 단계가 필요합니다. 도움말에서 설정 방법과 문제 해결 방법을 안내합니다.

개인정보 처리

자막 파일과 설정은 Mac에 보관합니다. 사용자가 직접 켜기 전에는 사용 통계를 보내지 않습니다. 동의하지 않아도 모든 앱 기능을 사용할 수 있습니다. 자세한 내용은 개인정보 처리방침에서 확인하세요.
