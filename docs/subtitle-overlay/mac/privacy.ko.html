이 페이지는 macOS용 Safari의 Subtitle Overlay에 적용됩니다.2026년 10월 10일 갱신.

핵심 안내

불러온 자막 파일, 자막 시간, 모든 모양 설정은 Mac에 보관합니다. 어디에도 업로드하지 않습니다.

앱이 연결하는 서비스는 두 곳뿐입니다. 자막을 검색할 때 OpenSubtitles에 연결합니다. 사용자가 직접 사용 통계를 켜면 PostHog에 연결합니다. 그 전에는 사용 통계를 보내지 않습니다.

계정, 로그인, 광고, 광고 식별자, 세션 재생은 없습니다. 개인정보를 판매하거나 공유하지 않습니다.

Mac에 보관하는 정보

  • 불러오거나 다운로드한 자막 파일과 본문.
  • 자막 시간 보정값, 글꼴, 크기, 색상, 배경, 위치 설정.
  • 같은 영상을 다시 열었을 때 자막을 복원하는 데 쓰는 최근 자막 기록.

이 정보는 확장 프로그램의 로컬 저장소에 보관합니다. 앱을 제거하면 함께 지워집니다.

자막 검색

자막을 검색하면 api.opensubtitles.com에 검색어와 필터를 보냅니다. 사용자가 선택한 자막 파일을 다운로드합니다. OpenSubtitles는 독립된 서비스이며, 자체 개인정보 처리방침과 일일 한도가 있습니다.

검색하지 않으면 OpenSubtitles에 연결하지 않습니다.

동의한 경우에만 보내는 사용 통계

사용자가 직접 허용하기 전에는 사용 통계를 보내지 않습니다. 동의를 거절해도 모든 앱 기능을 사용할 수 있습니다. 동의 절차를 건너뛰거나 “Not now”를 선택한 경우에도 같습니다. 언제든 Settings → General에서 선택을 바꿀 수 있습니다.

사용 통계를 허용하면 그 시점에 임의의 설치 식별자를 만듭니다. 기능 사용 이벤트를 us.i.posthog.com으로 보냅니다. 이벤트에는 다음 정보가 포함될 수 있습니다.

  • 사용한 기능과 성공·실패 여부.
  • 오류 유형이나 걸린 시간 같은 진단값.
  • 사이트의 호스트 이름. 예: example.com.
  • 페이지 주소를 SHA-256으로 단방향 해시한 뒤 16자로 줄인 값. 같은 영상을 다시 방문했는지, 새 영상을 방문했는지 구분하는 데 사용합니다.

전체 페이지 주소, 경로, 쿼리 문자열, 자막 본문, 검색창에 입력한 내용, 페이지 내용, 영상, 오디오는 사용 통계로 보내지 않습니다.

PostHog는 연결 IP 주소를 받으며 대략적인 위치를 추정할 수 있습니다. 설치 식별자는 같은 설치에서 발생한 이벤트를 연결합니다. 따라서 이 정보는 완전한 익명 정보가 아니라 가명 처리된 정보로 설명합니다.

공유를 끄면 이후 사용 통계를 보내지 않습니다. 기기의 식별자를 지우고 아직 보내지 않은 이벤트도 버립니다. 이미 서버가 받은 기록은 지우지 못합니다. 기존 기록을 지우려면 아래 방법으로 삭제를 요청하세요.

이 버전에서 제공하지 않는 기능

Chrome 버전의 일부 기능은 Mac 앱에 없습니다. Safari는 확장 프로그램에 필요한 오디오 캡처 기능을 제공하지 않습니다. 따라서 Mac 앱에는 다음 기능이 없으며 관련 네트워크 요청도 보내지 않습니다.

  • 오디오 캡처, 음성 인식, 음성 모델 다운로드.
  • 라이선스 키, 라이선스 검증, 구독, 모든 종류의 인앱 구매.
  • 앱 자체에 결제 기능이 없으므로 결제 처리 서비스에 연결하지 않습니다.
