두 파일 모두 위 영상에 맞춰 시간을 설정했습니다. 문자 인코딩 자동 감지도 확인할 수 있도록 영어와 한국어 자막을 준비했습니다.

나중에도 참고할 수 있도록 이 파일들을 같은 주소에 보관합니다.

사용 방법

  1. Safari 설정의 확장 프로그램에서 Subtitle Overlay를 켜세요.
  2. 이 페이지로 돌아오세요. Safari 도구 막대에서 Subtitle Overlay를 누르세요. Always Allow on This Website를 선택하세요. Safari 확장 프로그램은 처음에는 어떤 페이지에도 접근할 수 없습니다. 이 단계를 거치지 않으면 영상 위에 자막이 나타나지 않습니다.
  3. 위 영상을 재생하세요.
  4. demo-en.srt를 다운로드하세요. Finder에서 자막 파일을 영상에 끌어 놓으세요. 자막이 바로 나타납니다.
  5. , 또는 .로 시간을 조절하세요. + 또는 -로 크기를 조절하세요. 포인터를 페이지 오른쪽 가장자리로 옮기면 Sync Timeline이 열립니다. 모든 자막 줄을 보고 원하는 줄로 이동할 수 있습니다.

이 페이지에서는 계정, 로그인, 결제가 필요하지 않습니다. 자막 파일은 Mac에 보관합니다.
